# 動動腦

給爸媽在手機上玩的益智遊戲。一個連結、一個主畫面圖示，裡面三款遊戲。

**線上玩：** https://xd1104.github.io/brain-boosting-games/

## 三款遊戲

| 遊戲 | 難度 | 說明 |
|---|---|---|
| **數獨** | 六階（入門 6×6 → 地獄 9×9） | 題目即時生成、永不重複，每題保證只有一個答案 |
| **五子棋** | 三級電腦（隨便下／會擋你／會設陷阱） | AI 是本機計算，不連網、不呼叫任何服務 |
| **猜數字** | 四階（3 位數 → 4 位數可重複） | 幾 A 幾 B |

還有腦力點、每日挑戰、商店。

## 為長輩做的設計

- 按鈕最小 56px，字體可在大廳切換「標準／大」
- **沒有倒數、沒有 Game Over**，答錯只是溫和提示
- 數獨用**兩段式輸入**：點格子只是選取，下方大鍵盤才是填入，點錯沒有代價
- 五子棋**按住棋盤會出現放大鏡**，放開才落子；「悔一步」無限次不扣分
- 數獨的「填錯馬上變紅」可以自己關掉，關掉時腦力點多給四成
- 深色／淺色主題都支援，跟著手機設定走

## 技術

純前端，**沒有任何外部相依**：不載入字型、不呼叫 API、不用框架。
所有紀錄存在瀏覽器的 localStorage，換手機不會跟著走。

## 開發

原始碼在 `src/`，`index.html` 是合併出來的成品（會進版控，因為 GitHub Pages 直接吃它）。

```bash
node build.js      # 產生 index.html
node server.js     # 開發用伺服器，每次請求都重新合併，改完重整就看得到
```

加一款新遊戲：在 `src/games/` 放 `xxx.js` 和 `xxx.css`，用 `App.register({...})` 登記，
再把檔名加進 `build.js` 的清單。登記順序就是大廳卡片的順序。
