# 動動腦

給爸媽在手機上玩的益智遊戲。一個連結、一個主畫面圖示，裡面三款遊戲。

**線上玩：** https://xd1104.github.io/brain-boosting-games/

## 三款遊戲

| 遊戲 | 難度 | 說明 |
|---|---|---|
| **數獨** | 六階（入門 6×6 → 地獄 9×9） | 題目即時生成、永不重複，每題保證只有一個答案 |
| **數織** | 五階（5×5 → 10×10 稀疏） | 即時生成，保證「只靠推理解得出來、不用猜」 |
| **五子棋** | 兩級電腦（會擋你／會設陷阱） | AI 是本機計算，不連網、不呼叫任何服務 |
| **猜數字** | 四階（3 位數 → 4 位數可重複） | 幾 A 幾 B |

還有腦力點、每日挑戰、商店。

### 五子棋的兩級差在哪

兩級都會擋活三、衝四。差別在**雙重威脅**（雙三、四三 —— 同時兩個方向要成五，只擋得了一邊）
和**算殺**（一路衝四逼到底的必勝序列）：

- **會擋你**：只看單一威脅，會被雙重威脅打敗
- **會設陷阱**：偵測雙重威脅，對手還沒做出來就先佔掉交會點；自己也會主動做；
  另外會算殺，對手一漏防就抓住

實測（`scratchpad/bench.js` 那類測試台，每組 50 局，對手是會設陷阱的機器人）：

| 對手漏防率 | 會擋你 | 會設陷阱 |
|---|---|---|
| 0%（滴水不漏） | 輸 16 · 贏 7 · 和 27 | **輸 0** · 贏 0 · 和 50 |
| 15% | 輸 18 · 贏 2 · 和 30 | **輸 0** · 贏 6 · 和 44 |
| 30% | 輸 9 · 贏 3 · 和 38 | 輸 1 · **贏 15** · 和 34 |

意思是：**會擋你**每個程度都打得贏；**會設陷阱**對認真防守的人守得住和局，
對方一鬆手就被抓死。每手計算最久 15 毫秒。

沒有再往上的第三級 —— 試做過「會算殺」獨立一級，實測跟「會設陷阱」在防守嚴密時
完全沒有差別（各 40 局全平手），做成一級只是名字好聽，所以把算殺併進「會設陷阱」，
不另外開一級。

## 為長輩做的設計

- 按鈕最小 56px，字體可在大廳切換「標準／大」
- **沒有倒數、沒有 Game Over**，答錯只是溫和提示
- 數獨用**兩段式輸入**：點格子只是選取，下方大鍵盤才是填入，點錯沒有代價
- 五子棋**按住棋盤會出現放大鏡**，放開才落子；「悔一步」無限次不扣分
- 數獨、數織的「填錯馬上變紅」可以自己關掉，關掉時腦力點多給四成
- 數織難度到 10×10 就不再放大盤面（12×12 每格只剩 23px、提示字 11px，點不準也看不清），
  再往上改用「圖案越稀疏、越要推理」加難度
- 深色／淺色主題都支援，跟著手機設定走

## 技術

純前端，**沒有任何外部相依**：不載入字型、不呼叫 API、不用框架。
所有紀錄存在瀏覽器的 localStorage，換手機不會跟著走。

## 開發

原始碼在 `src/`，`index.html` 是合併出來的成品（會進版控，因為 GitHub Pages 直接吃它）。

```bash
node build.js      # 產生 index.html
node server.js     # 開發用伺服器，每次請求都重新合併，改完重整就看得到
```

加一款新遊戲：在 `src/games/` 放 `xxx.js` 和 `xxx.css`，用 `App.register({...})` 登記，
再把檔名加進 `build.js` 的清單。登記順序就是大廳卡片的順序。
